# 🎬 Theatre Seat Booking System

A command-line based theatre seat booking system built using Python.

The application allows users to view seat availability, book seats, cancel bookings, and view revenue collection.

---

## 🚀 Features

- View seat layout
- Book multiple seats
- Cancel booked seats
- Dynamic ticket pricing by row
- Booking history stored in files
- Revenue and seat collection report

---

## 🧰 Technologies Used

- Python
- File Handling
- Datetime Module
- CLI Interface
